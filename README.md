# Sift Weapons (Freshlol Style) - Fabric 26.2

Custom weapon progression mod inspired by Freshlol SMPs.

## Features
- Players spawn with **Level 1 Spear** and **Level 1 Mace**
- Get a kill with the weapon → it upgrades (max Level 14)
- **Hard limits**:
  - Only **1 God Mace**
  - Only **1 God Spear**
  - Only **2 Sift Maces**
- **Sift Mace**:
  - Recipe: Mace / Elytra / Mace  
               Diamond Block / Netherite / Diamond Block  
               Mace / Elytra / Mace
  - Right-click = strong dash (~20 blocks)
  - In inventory = permanent Strength III + Speed III

## Download
Check the [Releases](https://github.com/sutijimat-rgb/SiftWeaponsMod-Fabric/releases) page for the built `.jar`.

Put the jar in your `mods` folder together with **Fabric API** for Minecraft 26.2.

## Build yourself
Requires Java 25+.
```bash
./gradlew build
```
Jar appears in `build/libs/`.
